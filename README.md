🎬 CineMind
Stop Scrolling. Start Discovering.

CineMind is an AI-assisted movie discovery platform that understands what you feel like watching.

Instead of:

❌ Scrolling endlessly
❌ Random YouTube results
❌ Generic filters

You can simply type:

“Feel-good movies for a rainy evening”
“Mind-bending sci-fi like Interstellar”
“Light comedy to watch with family”

And CineMind suggests movies instantly.

✨ What Makes It Different?

🧠 Uses Generative AI to understand natural language
🎥 Fetches real-time movie data from TMDB
🔐 Secure JWT-based authentication
🎬 Dynamic trailer playback
🎨 Clean Netflix-style UI

This is not a rule-based filter system — it understands intent.

🔍 Try Sample Queries

Copy and paste these inside the app:

Emotional movies but not too sad

Motivational movies about success

Thriller movies with unexpected endings

Romantic comedy for weekend

⚙️ How It Works (Simple Flow)

User Query
⬇

⬇

⬇

⬇
UI displays movies + trailers

🚀 Quick Setup
1️⃣ Clone the repo
git clone <repo-link>
cd cinemind

2️⃣ Install dependencies

Backend:

cd backend
npm install


Frontend:

cd frontend
npm install

3️⃣ Add Environment Variables (.env in backend)
TMDB_API_KEY=your_tmdb_key
GEMINI_API_KEY=your_gemini_key
JWT_SECRET=your_secret

4️⃣ Run the App

Backend:

npm start


Frontend:

npm start
